# Support

## Project Help

Use [GitHub Issues](https://github.com/KarmenLoop/user-behavior-personalization/issues) for non-sensitive questions, reproducible bugs, and feature requests.

Before reporting a problem, read [Quick Start](docs/quickstart.md), [Host Integration](docs/host-integration.md), and [Evaluation](docs/evaluation.md).

Include:

- Package version or commit.
- Agent host and version.
- Which storage, lifecycle, and synchronization capabilities are actually enabled.
- A short synthetic conversation reproducing the issue.
- Expected and actual behavior.
- Relevant sanitized version or checkpoint information.

## Common Capability Questions

The skill does not run a model, create a timer, connect a messaging account, provide cloud storage, or grant filesystem permissions. Those operations belong to the host. Describe the host configuration when asking about them.

## Security Reports

Follow [SECURITY.md](SECURITY.md). Do not publish real user data or vulnerability details in a public support request.

## Maintainer Contact

The project owner is [KarmenLoop](https://github.com/KarmenLoop). No external email address, sponsorship program, response-time promise, or commercial support offering is asserted by this package.
