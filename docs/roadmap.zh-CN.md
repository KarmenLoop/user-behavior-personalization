# 个性化路线图 — v0.7.0

[English](roadmap.en.md) · [中文](roadmap.zh-CN.md)

本路线图仅涉及 user-behavior-personalization。方向 1–3 已实现，并记录了有明确范围的本地与真实提供方验收。发布检查和公开交付分别留证。方向 4–6 仍为计划。

| 方向 | 状态 | 范围与证据边界 |
| --- | --- | --- |
| 1. 真实语义学习闭环 | 已实现，已记录有明确范围的验收 | 用已配置模型分析用户明确选定、有权使用的片段；保留准确引文，生成待审提案，由用户决定是否采用。原有离线措辞学习仍可用。调用完成不能证明语义解释正确。 |
| 2. 条件偏好 | 已实现，已记录有明确范围的验收 | 按任务类型、受众、阶段应用已确认偏好；纠正时保留条件，解释排除原因，对同等具体的冲突暂不选择。未指定的任务条件不匹配要求该条件的偏好。 |
| 3. 真实模型回答对比 | 已实现，已记录有明确范围的验收 | 相同模型与判断要求生成两条真实回答，随机分配 A/B 身份，支持平局与都不选；偏好投票和用户报告的正确性分开记录，提供明确的揭示与删除控制。 |
| 4. 持续多轮反迎合评估 | 计划中 | 在真实、持续的对话中用独立证据评估。现有判断要求与单次回答对比，不能证明模型在多轮中能抵抗迎合。 |
| 5. 完整原生宿主集成 | 计划中 | 验收实际支持的 Codex、Cursor 宿主会话全链路。现有配置、包装器与工作台证据只覆盖较窄路径。 |
| 6. 更低摩擦的反馈体验 | 计划中 | 降低审核和反馈成本，同时保留明确选源、用户控制，以及偏好与正确性的区分。现有操作控件不代表这一完整方向已验收。 |

回答对比投票记录使用体验，不是训练奖励、事实裁决，也不会自动修改已有偏好。路线图不声称完成模型训练、测得质量提升或消除迎合。

已实现流程见[语义学习指南](semantic-learning.zh-CN.md)。[既有评估记录](evaluation.zh-CN.md)保留早期失败诊断和较窄验收结果；新增证据不能覆盖这些历史记录。
