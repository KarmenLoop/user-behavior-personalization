[English](evaluation.md) · [中文](evaluation.zh-CN.md)

保存偏好、宿主加载、回复实际遵守、体验确实改善，是四个不同结果。报告时应始终分开。

## 复现本地流程

在解压包内使用 Python 3.11+：

```sh
python3 -B scripts/check_package.py
python3 -B -m unittest discover -s tests -v
python3 -B scripts/check_publication.py
python3 -B scripts/demo_learning.py --root ../new-synthetic-acceptance
```

演示要求新的私有目录。它用合成输入执行真实 CLI 进程和 SQLite 写入，覆盖观察、审查、重启后检索、场景与用户隔离、暂停、导出、删除、防重放及重置。结束时档案暂停，内容清空，保留抑制哈希；不调用模型。

## 验收矩阵

| 检查项 | 应保留的证据 |
|---|---|
| 明确偏好 | 新来源、当前版本、持久规则、随后匹配检索 |
| 场景边界 | `art` 不匹配 `cartography`；另一用户看不到规则 |
| 重复输入 | 同一事件重放不增加支持度 |
| 独立会话 | 一个会话重复多次不能达到三个会话门槛 |
| 反馈冲突 | 展示反对证据，未经确认的偏好不进入检索 |
| 时效 | 旧证据衰减或超出 90 天窗口，候选就绪还需近期支持 |
| 过时审查 | 证据或版本变化后，旧审查不能直接生效 |
| 更正 | 新的明确纠正替换相应默认值 |
| 遗忘 | 受影响历史、证据、派生规则及受控产物删除，重放被阻止 |
| 暂停 / 重置 | 普通使用停止，导出删除可用，重置后暂停 |
| 宿主传输 | 真实 MCP 管道 initialize、tools/list 和工具调用 |
| 模型回复 | 真实回答采用无害偏好，纠正后随之改变 |
| 用户收益 | 用户在可比任务中反馈是否更好用 |

公开证据使用合成示例。支持度不是“理解用户分数”，确定性测试通过也不能证明心理学有效性。

## 由真人判断体验

先选少量代表任务：进度汇报、代码审查、学习练习和偏好变化。事先确定何谓改善，例如是否少了重复纠正格式。记录真实反馈，不将沉默视为认可；个性化反而造成干扰的情况也要保留。

不要从一个任务推断整体人格；可选学习练习的答对率不是智力评估，也不是记录学习行为的授权。用户可以跳过练习或关闭记忆。

## 发布检查

核对实际提交、版本、压缩包 SHA-256、中英文链接、图解与源码哈希、解压包行为和真实 CI 结果。许可与声明保持完整；失败和未验宿主继续可见。只发布合成示例与原创图解，不发布真实档案或凭据。
